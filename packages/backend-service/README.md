## Example of simple backend service for Confidential Transfers

This is a simple backend service for Confidential Transfers that allows you to store user entropy and generate proofs for confidential operations.

## Installation

```bash
npm install
```

## Usage

0. Download the zk keys as mentioned in [sdk](../sdk/README.md)
1. Start the backend service:

```bash
npm run start:dev
```
